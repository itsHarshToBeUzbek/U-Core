# U-Core

Расширение Chrome (Manifest V3) для пунктов выдачи Uzum ТАШ-120 и FrТАШ-223.
Работает поверх WMS на `dp.uzum.uz`: считает инкассацию, печатает инфолисты,
акты приёма-передачи и акты на диагностику, собирает данные приёмки по кнопке,
ведёт инвентаризацию по ячейкам и подсказывает ячейку при размещении.

В WMS оно ничего не нажимает и ничего не меняет — только читает и печатает.

## Установка

Распаковать в постоянную папку, открыть `chrome://extensions`, включить режим
разработчика, «Загрузить распакованное расширение». Подробно, для человека,
который делает это впервые, — в [ДЛЯ-ОПЕРАТОРА.md](ДЛЯ-ОПЕРАТОРА.md).

## Тесты

```sh
sh tests/run-all.sh
```

Гонять целиком, а не только то, что относится к правке: связи здесь
неочевидные — тест приёмки уже падал из-за изменения в `popup.js`. Для
сквозных нужен `playwright` и Chromium; путь к браузеру, если он лежит не
там, где playwright его ищет, передаётся через `CHROME_PATH`.

Каждая проверка испытана «наоборот»: баг возвращали в код и убеждались, что
она падает и называет причину словами. Проверка, которая не падала ни разу,
ничего не охраняет.

## Чего в этом репозитории НЕТ

Ниже перечислено то, что существует — или существовало — вне git. Это не
список пожеланий, а список того, чем нельзя пользоваться, пока оно сюда не
попало.

**Большая часть тестов.** В `tests/` заложено начало — 137 проверок, прогон
`sh tests/run-all.sh`. Набор, описанный в прежней редакции технического
описания, втрое больше: `test-allocation.mjs` (43 проверки на логику
раскладки), мок-сервер WMS и 21 файл сквозных тестов, около 815 проверок.
Их здесь нет ни в одном коммите. Логика раскладки и весь сбор данных из WMS
сейчас не покрыты ничем — а это как раз те две части, которые теряли по
полсотни заказов и прятали недостачу.

**ARCHITECTURE.md** — 47 правил, каждое с указанием, после какой поломки оно
появилось. Самые дорогие семь пересказаны в техническом описании §9, остальные
сорок не записаны нигде.

**WMS-API-NOTES.md** — живые замеры API: формы ответов, ловушки, даты.

**PVZ-LAYOUT-TASH120.md** — схема зала ТАШ-120.

**RECOMMENDATION-VARIABLES.md** — переменные раскладки, на которые ссылается
`allocation-core.js` и комментарии в `pvz-config.json`.

**PROJECT-OVERVIEW.md** — упомянут в записке как устаревший на много версий.
Его здесь тоже нет; техническое описание заменяет его целиком.

Если где-то сохранились архивы `u-core-*.zip` или старый `updates.txt` —
из них восстанавливается и это, и пробел в журнале версий между 1.4.0 и 2.3.x.

## Границы

Они не «на всякий случай», на них расширение построено:

* только GET, единственное исключение — `POST /de/sku/basic/all/id`
  (справочник товаров, он ничего не меняет);
* кнопки в WMS жмёт только человек;
* пароль не хранится и не спрашивается;
* данные собираются только по нажатию;
* наружу не уходит ничего из работы ПВЗ. Единственное исключение включает сам
  оператор — перевод названий товаров, и тогда наружу уходят только названия.
